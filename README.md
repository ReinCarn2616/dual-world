# 光影之间 · dual-world

一款 **2D 双世界解谜平台跳跃游戏**。

同一张地图同时存在**光**与**暗**两个世界：起点与终点在两边完全相同，路线却截然不同。
你可以在任意时刻切换世界 —— 站在地上、奔跑中、甚至**跳到半空中**都行，位置和速度原样保留。

这个设计带来一条贯穿全作的铁律：**任何一个世界都无法单独通关**。
卡住的时候，答案往往不是"再跳高一点"，而是"换个世界看看脚下"。

- 纯网页游戏，打开就玩：**零安装、零加载、可离线**
- **11 关**：8 关教学 + 3 关进阶；进阶关地图比屏幕大，**摄像机跟随**（像马里奥那样横向滚动）
- 可变高度跳跃、半空换世界、每关计时与最佳成绩
- 键盘可完全自定义，内置"看本关解法"演示

## 立刻开始

**在线玩（推荐）**：<https://reincarn2616.github.io/dual-world/>

**在本地玩**：

| 系统 | 做法 |
| --- | --- |
| Windows | 双击 [`start-game.bat`](start-game.bat) |
| macOS / Linux | 终端执行 `./start-game.sh` |

启动脚本会自己找 Node.js，找不到就**自动安装**（Windows 优先用 winget，不行就下载便携版到用户目录，不需要管理员权限；macOS/Linux 会依次尝试 brew / apt / dnf / pacman，最后回退到官方压缩包）。
装好后它会启动一个本地服务器并自动打开浏览器。系统里已经有 Python 也行，脚本会自动改用它。

> 为什么需要一个小服务器？因为游戏用的是浏览器原生的 ES Modules，直接双击 `index.html`（`file://`）会被浏览器的跨域策略拦住。除此之外**没有任何依赖、没有构建步骤、不需要 npm install**。

## 操作

| 操作 | 默认按键 |
| --- | --- |
| 左右移动 | `A` / `D`（也可用 `←` `→`） |
| 跳跃（按住跳得高，轻点跳得矮） | `空格`（也可用 `W` / `↑`） |
| **切换世界** | `J`（也可用 `Shift`） |
| 重开本关 | `R` |
| 暂停 / 菜单 | `Esc`（也可用 `P`） |
| 看本关解法演示 | `H` |

所有按键都能在「设置 → 按键」里重绑，也支持给一个动作绑定多个键。

## 玩法要点

- **换世界会完整保留你的位置和速度**。这意味着你可以用一次跳跃，在前半段属于光世界、后半段属于暗世界 —— 很多关卡的正解就是"跳到最高点时换世界"。
- **换世界失败没有代价**：如果目标世界里你现在的位置是墙，切换会失败（画面闪红、轻微震动），你留在原世界，位置速度一点都不变。所以可以放心试。
- **目标是那扇门**。碰到熔岩或掉出地图就会死亡，回到本关起点重来，计时继续累加。
- **看不清就去试、去记**。另一个世界的形状默认不可见（残影效果默认关闭）；如果你觉得太难，可以在「设置 → 显示 → 显示另一个世界的残影」里打开，它会用半透明灰色画出另一世界的方块与危险。

## 关卡

**教学关（8 关）** —— 每关只教一件事，画面正好装下整张地图。

| # | 名称 | 教什么 |
| --- | --- | --- |
| 1 | 切换 | 换世界，以及"位置和速度原样保留" |
| 2 | 立足 | 另一个世界的脚下可能没有地 |
| 3 | 连跳 | 连续换世界跨越一段路 |
| 4 | 窄门 | 只有特定世界才过得去的口子 |
| 5 | 上升 | 用换世界接续跳跃、往上爬 |
| 6 | 回头 | 别只顾往前，答案可能在身后 |
| 7 | 双坑 | 两个世界的坑位置不同，交替使用 |
| 8 | 之间 | 综合运用前面学到的一切 |

**进阶关（3 关）** —— 地图远大于屏幕，摄像机跟随，终点在出发点之外。

| # | 名称 | 一句话 |
| --- | --- | --- |
| 9 | 三层折返 | 三层楼 + 两条竖井；终点在出生点正上方 12 行，开局根本看不见，得先往右再折返向上 |
| 10 | 镜廊 | 上一关的镜像世界：方向全部反过来，最后一段要连换两次世界 |
| 11 | 回廊 | 楼梯改成往右上爬，终点在二层另一头；一条矮走廊逼你边跑边换世界 |

## 特性

- **固定物理步长**：游戏逻辑按 1/120 秒推进，60 Hz 与 144 Hz 显示器上的跳跃高度完全一致。
- **每关计时与最佳成绩**：通关时间记在本机（`localStorage`），在该关结算界面查看，可在设置里清空。
- **全键盘可玩，也能用鼠标**：主菜单分成「开始游戏 / 选择关卡 / 设置 / 操作说明」四个页签，键盘方向键与鼠标都支持。
- **没有网络请求**：美术与音效都在本地，音效是程序合成的，游戏可完全离线运行。
- **残影开关**：想挑战就别开，想过关就打开。

## 常见问题

**打不开、白屏？**
请用启动脚本（或任意静态服务器）打开，不要直接双击 `index.html` —— 浏览器的跨域策略会拦住 ES Modules。

**手机能玩吗？**
可以打开、可以看，但**目前只有键盘操作，没有触屏按键**。

**某一关卡住了？**
游戏内按 `H`（或暂停菜单里的「看本关解法演示」），会播放这一关的标准通关路线。

**想清空成绩？**
设置 → 成绩 → 清空成绩。想恢复默认按键：设置 → 按键 → 恢复默认。
